# MyPets 宠物形象运行时

## 当前范围

桌面端现在可以根据宠物实例中的以下三个字段选择形象包：

```text
template_id
identity_version
asset_version
```

形象包可以采用两种渲染方式：

```text
frames       逐帧 PNG、WebP 或其他 Qt 可读取图片
spritesheet  单张精灵表加行列坐标
```

窗口切换宠物时先完整解析 Manifest、校验路径、加载全部运行时动作；只有所有步骤成功后才原子替换当前素材。失败时继续显示旧形象，不把半加载状态暴露给用户。

## 模块结构

```text
PetAssetCatalog
├── bundled packages
├── local version cache
└── public demo fallback

DynamicPetWindow
├── existing PetWindow behavior state machine
├── frame package loading
├── spritesheet cell extraction
└── atomic hot switching
```

`PetWindow` 的移动、睡眠、互动和动画时序逻辑没有复制到形象系统。`DynamicPetWindow` 只负责提供可替换的帧集合。

## Manifest 身份

每个运行时 Manifest 必须声明：

```json
{
  "schema_version": "2.1",
  "template_id": "sun-sun",
  "identity_version": "1.0.0",
  "asset_version": "2.0.0"
}
```

三元组必须与宠物实例完全一致。缓存安装时再次核对身份，防止服务端返回错误模板或旧版本包。

## 逐帧格式

现有公开演示素材继续使用逐帧格式：

```json
{
  "animations": {
    "idle": ["idle/idle_01.png"],
    "walk": ["walk/walk_01.png"]
  }
}
```

所有文件路径均相对 Manifest 所在目录。

## 精灵表格式

精灵表声明固定网格：

```json
{
  "renderer": {
    "kind": "spritesheet",
    "path": "spritesheet.webp",
    "columns": 8,
    "rows": 11,
    "cell_width": 192,
    "cell_height": 208
  },
  "animations": {
    "idle": [
      {"row": 0, "column": 0},
      {"row": 0, "column": 1}
    ]
  }
}
```

运行时要求图片像素尺寸严格等于：

```text
columns × cell_width
rows × cell_height
```

坐标越界、图片为空或尺寸不一致都会阻止加载。

## 动作降级

窗口目前需要以下运行时动作：

```text
idle
walk
sit
sleep
wave
happy
shy
surprised
annoyed
sleepy
curious
selfie
drag
```

形象包不必单独制作全部动作，但必须配置明确的降级关系：

```json
{
  "fallback_actions": {
    "sit": "waiting",
    "sleep": "waiting",
    "curious": "review"
  }
}
```

降级链不得形成循环，最终必须落到非空动画。

## 路径安全

Manifest 内所有素材路径必须满足：

- 相对路径；
- 不包含 `..`；
- 不包含驱动器盘符；
- 不包含 URL；
- 解析后仍位于形象包目录内。

可选 `files` 字段还可以声明 SHA-256 和文件大小。缓存安装时会验证这些值。

## 本地缓存

缓存目录：

```text
%LOCALAPPDATA%/OnePicDesktopPet/pet-assets/
  <template_id>/
    <identity_version>/
      <asset_version>/
        manifest.json
        ...
```

安装步骤：

```text
读取源 Manifest
→ 校验身份和全部文件
→ 复制到 .installing 临时目录
→ 再次从临时目录完整校验
→ 替换正式版本目录
→ 删除旧备份
```

缓存选择优先级：

```text
精确版本本地缓存
→ 精确版本内置包
→ 公开演示兼容形象
```

`local.default` 保留原有私有素材确认流程，不绕过角色验收门禁。

## 内置宠物

当前仓库内置：

- 公开演示逐帧宠物；
- 榫榫精灵表宠物。

榫榫的运行时包只包含：

```text
outputs/sun-sun/pet.json
outputs/sun-sun/manifest.json
outputs/sun-sun/spritesheet.webp
```

`work/`、QA 图片、提示词和中间产物不会进入 PyInstaller 发布包。

## 热切换

切换步骤：

```text
读取目标宠物版本
→ 解析并加载完整形象包
→ 暂停当前动画计时器
→ 替换帧集合和走路位移曲线
→ 清空 DPI 与遮罩缓存
→ 根据新素材比例调整窗口
→ 从待机状态恢复
```

窗口位置会经过屏幕边界重新约束。处于边缘吸附模式时，切换完成后重新计算吸附位置。

## 管理员校验

逐帧和精灵表统一使用：

```powershell
python tools/validate_pet_manifest.py <manifest.json>
```

校验范围：

- 版本字段；
- 动作完整性与降级循环；
- 精灵表网格和坐标；
- 路径穿越；
- 素材存在性；
- 可选文件大小和 SHA-256；
- 本地内置宠物定义。

## 当前限制

本阶段尚未实现：

- 从云端 CDN 自动下载形象包；
- 管理员发布 API；
- 包签名和公钥验证；
- 增量资源更新；
- 成长阶段、服装和配饰分层；
- 每只宠物独立托盘图标；
- 精灵表方向帧直接选择。

当前行走仍使用一组向右动作，并由现有窗口逻辑在向左移动时水平翻转。云端下载应在后续阶段复用 `PetAssetCatalog.install_package()` 的校验和原子安装边界。
