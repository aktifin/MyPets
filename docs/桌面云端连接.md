# MyPets PC 桌面云端连接

## 当前范围

PC 客户端现在可以连接仓库中的 FastAPI 后端，完成：

- 账户登录与注册；
- 当前电脑设备绑定；
- 设备密钥交换短期访问令牌；
- 首次完整同步；
- 定时增量同步；
- 服务端设备当前宠物切换；
- 云端宠物资料写入本地 SQLite 缓存；
- 托盘显示连接状态和宠物列表。

本阶段没有加入好友、串门、聚会、MyReminder 云同步、AI 聊天或语音服务。

## 模块结构

```text
DesktopPetApplication
├── PetWindow
├── LocalStateStore
├── PetRegistry
├── CloudApiClient
├── CloudSessionController
├── CredentialStore
└── CloudLoginDialog
```

### `CloudApiClient`

使用 Qt 原生 `QNetworkAccessManager`，不阻塞 GUI 线程。

负责：

- JSON 请求；
- OAuth2 表单登录；
- Bearer 认证头；
- HTTP 状态和 FastAPI 错误解析；
- 完整快照与增量事件请求；
- 修改本设备当前宠物。

它不直接写数据库，也不保存凭据。

### `CloudSessionController`

负责按顺序编排：

```text
账户登录
→ 绑定设备
→ 交换设备令牌
→ 保存设备密钥
→ 下载完整快照
→ 启动增量轮询
```

服务端响应必须先经过 `sync_apply.py` 的协议校验，再写入 SQLite。

### `CredentialStore`

Windows 正式运行使用 Windows Credential Manager。

只保存：

```text
服务地址
账户ID
设备ID
设备密钥
```

不会保存：

```text
账户密码
账户访问令牌
设备访问令牌
AI模型密钥
```

设备访问令牌只保存在进程内存中。

非 Windows 平台默认拒绝把设备密钥写入明文文件。测试使用显式注入的内存凭据仓库。

## 登录流程

用户从托盘选择：

```text
云端账户
→ 登录或注册…
```

登录窗口包含：

- 后端服务地址；
- 用户名；
- 密码；
- 注册显示名称；
- 密码确认。

密码字段在登录完成或关闭窗口时清空。

成功流程：

```text
POST /api/v1/auth/token
→ 取得短期账户令牌
→ POST /api/v1/devices/bind
→ 取得一次性设备密钥
→ POST /api/v1/auth/device-token
→ 验证设备凭据
→ 写入 Windows Credential Manager
→ GET /api/v1/sync/bootstrap
```

设备密钥只有在设备令牌交换成功后才会持久化，避免保存无法使用的绑定结果。

## 自动连接

配置文件只记录：

```json
{
  "cloud_base_url": "https://pets.example.com",
  "cloud_sync_enabled": true,
  "cloud_sync_interval_ms": 15000,
  "device_public_id": "稳定设备公开标识"
}
```

应用启动时：

```text
cloud_sync_enabled = false
→ 保持现有单机模式

cloud_sync_enabled = true
→ 从 Credential Manager 读取设备密钥
→ 交换设备访问令牌
→ 执行完整同步
```

默认不开启云端同步，因此本地开发服务未启动时不会影响桌宠启动。

## 增量同步

完整同步成功后，客户端按配置周期请求：

```text
GET /api/v1/sync/events?after_sequence=<cursor>
```

处理规则：

1. 从 SQLite 读取当前账户与设备同步游标；
2. 请求服务端增量语义事件；
3. 校验账户、设备、序号、时区和载荷；
4. 应用宠物或关系变更；
5. 单调推进游标；
6. `has_more=true` 时立即继续拉取下一页。

未知未来事件会被忽略，但游标仍推进，避免旧客户端永久卡住。

## 令牌失效

增量同步或完整同步返回 `401` 时，客户端最多自动重新交换一次设备令牌。

如果设备密钥本身失效：

- 删除本地 Credential Manager 凭据；
- 关闭自动同步；
- 提示用户重新登录；
- 不删除本地宠物缓存。

这可以处理服务端设备撤销和重新绑定后的凭据版本变化。

## 宠物切换

托盘菜单动态读取本地宠物缓存：

```text
切换宠物
├── 小白
├── 可乐
└── 本地默认宠物
```

在线时：

```text
PATCH /api/v1/devices/{device_id}/active-pet
→ 服务端确认
→ 更新本地当前宠物
```

离线时只修改本设备 SQLite，并明确提示该变化尚未同步。

当前窗口仍使用现有单套动画素材。宠物名称和当前选择已经切换，但按 `template_id` 和 `asset_version` 动态加载不同素材包属于下一阶段。

## 安全边界

- 云端地址不允许嵌入用户名、密码、查询令牌或 URL 片段；
- 配置 JSON 不包含任何密码、设备密钥或访问令牌；
- 账户令牌只用于绑定设备，不持久化；
- 设备密钥使用 Windows Credential Manager；
- 设备令牌只在内存中使用；
- 服务端设备撤销后，旧令牌和旧设备密钥不能继续同步；
- 网络请求不直接操作 `PetWindow`；
- 服务端响应必须完整校验后才能写入 SQLite。

生产环境必须使用 HTTPS。默认 `http://127.0.0.1:8000` 只用于本机开发。

## 当前限制

尚未实现：

- 刷新令牌；
- WebSocket 实时推送；
- 网络指数退避和随机抖动；
- 系统代理配置页面；
- 证书固定；
- 账户密码找回；
- 本地账户缓存清理向导；
- 按宠物模板动态切换动画素材；
- 离线主动变更上传接口。

在增加这些能力前，SQLite 仍只作为可重建缓存和本地显示状态使用。
