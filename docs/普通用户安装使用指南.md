# MyPets 普通用户安装与使用指南

适用版本：`0.3.0a1`（Alpha）

## 一、版本说明

当前版本适合小范围试用，不建议直接作为无人维护的正式生产软件分发。

Windows 客户端负责桌面宠物显示与交互；账户、宠物状态、好友、消息、提醒、串门和聚会等云端功能由 MyPets 服务端提供。

## 二、运行条件

- Windows 10 或 Windows 11，64 位；
- 可用的 MyPets 服务地址；
- 能访问服务地址的网络；
- 首次登录时由管理员或部署方提供服务地址，或使用本地开发体验模式。

## 三、使用客户端压缩包

1. 解压 `MyPets-Desktop-<版本>-windows-x64.zip`；
2. 保持解压目录结构不变；
3. 双击 `MyPets.exe`；
4. 首次运行按引导选择“本地体验”或“登录并同步我的宠物”；
5. 云端模式下填写服务地址，登录账户并完成设备绑定；
6. 登录后等待第一次同步完成。

不要直接从压缩包内部运行程序，也不要只复制单个 EXE 文件。程序依赖同目录中的运行库和素材文件。

## 四、本地一键体验

开发测试人员可以在项目目录运行：

```powershell
.\scripts\start_local.ps1
```

首次执行会安装依赖，时间取决于网络环境。脚本会同时启动本地服务、Web 门户和桌面宠物；关闭桌面宠物后，本次启动的本地服务会自动结束。

## 五、主要操作

### 桌面宠物

- 单击：打开快捷养宠面板；
- 双击：立即互动；
- 拖动：调整桌面位置；
- 右键：打开常用操作；
- 系统托盘：切换宠物、查看消息与待办、管理窗口和云端连接；
- 系统托盘“帮助与诊断”：查看运行环境、打开数据目录或导出诊断包。

### Web 用户门户

进入部署方提供的 `/portal` 地址，可进行：

- 创建、选择和配置宠物；
- 查看成长、任务和互动记录；
- 添加好友和管理共同照料；
- 发起或处理串门与聚会邀请；
- 查看消息、提醒、待办和处理记录；
- 修改账户显示名称和密码；
- 查看绑定设备、撤销不再使用的设备；
- 下载 Web 诊断信息。

## 六、设备管理

进入 Web 门户“设置”，在“登录设备与诊断”区域可以查看：

- 设备名称和平台；
- 绑定时间与最后在线时间；
- 当前设备是否仍然可用；
- 历史撤销时间。

点击“撤销此设备”后，该设备原有的设备令牌立即失效，再次使用云端功能时需要重新登录并绑定。撤销操作不会删除账户、宠物或历史数据。

## 七、常见问题

### 1. 桌面宠物没有出现

检查系统托盘是否已有 MyPets 图标。若宠物被隐藏，可通过托盘菜单重新显示。

### 2. 登录后一直显示离线

确认服务地址可访问，并在浏览器中打开服务的 `/health` 地址。健康检查应返回 `status: ok`。

### 3. 宠物形象回退为默认形象

通常表示当前设备尚未下载对应素材，或素材已撤销。保持网络连接并执行一次立即同步；若仍未恢复，请联系部署管理员。

### 4. 无法照料好友宠物

只有主人、共同主人或被允许远程照料的照料者可以执行照料。观察者和普通好友只能查看允许公开的信息。

### 5. 聚会邀请不能直接接受

聚会邀请必须进入聚会界面，选择一只由当前账户管理、目前在家且未参与其他串门或聚会的宠物。

### 6. 如何导出诊断信息

Windows 客户端：打开系统托盘，选择“帮助与诊断…”，点击“导出诊断包…”。

Web 门户：进入“设置”，在“登录设备与诊断”区域点击“下载诊断信息”。

桌面诊断包包含运行环境摘要和最多四份轮转日志；Web 诊断文件包含浏览器、服务状态和脱敏设备摘要。二者均不主动包含密码、访问令牌、设备密钥、消息正文、本地数据库或宠物原图。

## 八、隐私与安全提示

- 不要向他人提供密码、设备密钥或访问令牌；
- 公共电脑使用 Web 门户后应主动退出登录；
- 不再使用的设备可在 Web 门户自行撤销；
- 诊断文件只应发送给可信维护人员；
- 正式环境必须使用 HTTPS；
- 当前版本不包含 Agent、工具执行或电脑自动控制能力。

## 九、已知限制

- 暂无密码找回和账户自助注销；
- 暂无正式 Windows 安装程序和自动升级；
- 诊断日志仅从本批版本开始记录，无法恢复此前未记录的错误；
- 暂无 AI 文字聊天、有限记忆和语音交互；
- 暂无小程序或原生移动客户端；
- 多账户 Web 与 Windows 全流程仍需持续人工验收。
