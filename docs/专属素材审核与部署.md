# MyPets 专属素材审核与单宠部署（保留代码说明）

> 当前状态：默认屏蔽，不属于现阶段产品主流程。

运行配置：

```text
MYPETS_ENABLE_PET_REVIEW=0
```

关闭时，本文所述投稿、审核、制作、发布、私有下载和回退接口均不注册；`/admin` 管理台和用户门户“专属形象”入口也不可访问。数据库模型、历史数据和对象文件保留，已发布公共素材的只读目录继续提供服务。

仅在兼容测试或专项开发中，可显式设置 `MYPETS_ENABLE_PET_REVIEW=1` 恢复以下保留链路。

## 保留的技术链路

```text
用户原图投稿
→ 管理员原图审核
→ 人工制作工单
→ 声明式素材包校验
→ 独立部署审核
→ 私有不可变 Release
→ 单宠 active / previous 指针
→ 鉴权下载或显式回退
```

## 权限分离

| 操作 | 权限 |
|---|---|
| 投稿审核领取与工单处理 | `edit` |
| 批准或退回 | `review` |
| 发布和回退 | `publish` |
| 审计查询 | `audit` |

服务端仍保留制作产物上传者不能审核自己产物的约束。

## 保留的数据模型

```text
user_pet_asset_submissions
pet_asset_production_jobs
pet_asset_production_artifacts
pet_asset_production_reference_images
pet_asset_production_job_logs
pet_asset_deployment_reviews
pet_personal_asset_releases
pet_personal_asset_deployments
```

屏蔽功能不会删除这些表，也不会自动清理历史图片、ZIP 包、Release 或审计记录。

## 屏蔽范围

默认关闭时不加载：

```text
/api/v1/pet-asset-submissions...
/api/v1/pet-asset-production-jobs...
/api/v1/pets/{pet_id}/personal-asset-deployment
/api/v1/personal-asset-releases...
/api/v1/admin/pet-templates...
/api/v1/admin/pet-template-versions...
/api/v1/admin/pet-asset-submissions...
/api/v1/admin/pet-asset-production-jobs...
/api/v1/admin/pet-asset-deployment-reviews...
/api/v1/admin/pet-personal-asset-deployments...
/admin
```

同时停止加载：

```text
/portal/asset-submissions.js
/portal/asset-production.js
/admin/asset-submissions.js
/admin/asset-production.js
```

直接访问以上入口返回 404，不是仅通过 CSS 隐藏。

## 不受影响的能力

以下只读能力继续保留，以保障现有宠物正常运行：

```text
GET /api/v1/catalog/pet-assets
GET /api/v1/catalog/pet-assets/latest
GET /api/v1/assets/releases/{release_id}/package
```

桌面端仍可查询已发布官方素材、校验大小与 SHA-256，并安装到本地版本缓存。

## 后续策略

现阶段不继续建设宠物审核管理台、视觉版权治理、自动素材生产或专属 Release 客户端安装。后续产品确有需要时，再基于保留代码重新评估，而不是默认恢复全部运营链路。
