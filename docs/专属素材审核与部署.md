# MyPets 专属素材审核与单宠部署

## 范围

D3 将 D2 中已经通过 ZIP 安全校验和 13 种动作校验的制作产物，转换为可由指定宠物使用的私有不可变 Release。该链路不改变公共模板的 `stable` 通道，也不向无宠物访问关系的账户公开素材包。

```text
ready 制作工单
→ 编辑员提交部署审核
→ 审核员核验权利、视觉身份和兼容性
→ 发布员生成私有不可变 Release
→ 更新单宠 active / previous 指针
→ 更新宠物视觉版本并发送同步事件
→ PC 或用户端鉴权下载
```

## 权限分离

| 操作 | 权限 |
|---|---|
| 提交部署审核 | `edit` |
| 批准或退回 | `review` |
| 发布和回退 | `publish` |
| 查询审核记录 | `view` |

服务端额外要求制作产物上传者不能审核自己的产物。即使账户同时具备编辑与审核权限，该约束仍然生效。

## 数据模型

```text
pet_asset_deployment_reviews
pet_personal_asset_releases
pet_personal_asset_deployments
```

- `pet_asset_deployment_reviews`：一个制作产物最多一条独立审核记录，状态为 `pending / approved / rejected / published`。
- `pet_personal_asset_releases`：审核通过后生成的私有不可变 Release，显式关联审核、制作产物、宠物和模板版本。
- `pet_personal_asset_deployments`：按 `pet_id` 保存当前和上一 Release 指针，用于切换与回退。

## 审核硬门槛

批准操作必须同时满足：

1. 制作工单仍为 `ready`；
2. 制作产物、工单、宠物和目标模板版本关联一致；
3. 目标模板代码与宠物当前模板一致；
4. Manifest schema 为 2.0 或 2.1；
5. Manifest 中的模板、视觉版本和素材版本与目标模板版本一致；
6. 权利状态已人工核验；
7. 视觉身份一致性已人工核验；
8. 审核人不是制作产物上传者。

当前 D3 记录人工核验结论和兼容性检查结果。完整视觉身份特征档案与权利生命周期模型仍属于后续 E 阶段。

## 管理 API

```text
GET  /api/v1/admin/pet-asset-deployment-reviews
GET  /api/v1/admin/pet-asset-deployment-reviews/{review_id}
POST /api/v1/admin/pet-asset-production-jobs/{job_id}/submit-deployment-review
POST /api/v1/admin/pet-asset-deployment-reviews/{review_id}/approve
POST /api/v1/admin/pet-asset-deployment-reviews/{review_id}/reject
POST /api/v1/admin/pet-asset-deployment-reviews/{review_id}/publish
POST /api/v1/admin/pet-personal-asset-deployments/{pet_id}/rollback
```

提交审核按制作产物幂等：重复提交返回同一条审核记录，不重复创建审核对象。

## 用户与客户端下载

```text
GET /api/v1/pets/{pet_id}/personal-asset-deployment
GET /api/v1/personal-asset-releases/{release_id}/package
```

账户必须与宠物存在 `AccountPetRelation` 才能查询部署或下载对应 Release。下载响应使用私有、长期不可变缓存和 SHA-256 ETag；无权账户统一返回 404，避免泄露 Release 是否存在。

## 发布与回退

发布时：

- 从 D2 私有暂存对象复制生成新的不可变对象；
- 不复用或移动公共 `pet_asset_deployments` 的 `stable` 指针；
- 首次发布设置 `active_release_id`，后续发布把原 active 保存为 previous；
- 将模板版本、视觉版本和素材版本写回目标宠物；
- 增加宠物 `state_version`；
- 向所有与宠物有关联的账户发送 `pet_asset_version_changed` 事件；
- 写入管理员审计日志。

回退时交换 active 与 previous，并重新应用目标 Release 对应的版本。该设计保留一步快速恢复能力，同时所有 Release 本身保持不可变。

## 明确边界

- 不自动生成宠物图片或动作帧；
- 不允许制作完成后自动发布；
- 不把专属素材加入公开目录；
- 不覆盖公共模板稳定通道；
- 不允许 ZIP 中包含脚本、插件或可执行文件；
- 不在 D3 内实现完整版权撤销、到期和客户端缓存清除规则。
