# MyPets Web 用户门户 Phase1

## 建设目标

将 Web 端从分散的功能验证页面恢复并升级为可独立使用的云养宠用户门户，同时复用既有服务端权威业务接口，不另建成长、消息、提醒或素材状态机。

## 已完成范围

- 恢复登录、注册、账户设置、宠物管理、好友、共同照料和异步串门的完整 DOM 骨架；
- 移除与 CSP 冲突的内联事件和外部图片依赖；
- 新增首页 Dashboard，展示当前宠物、成长与羁绊、饱食、精力、清洁、心情及今日统计；
- 新增网页快捷照料，复用 `/api/v1/pets/{pet_id}/interactions/{action}`；
- 新增成长档案和互动履历，复用 growth/activity API；
- 新增分类消息中心、未读统计、会话消息查看和跨端已读；
- 新增提醒中心，展示今日待办、完成、贪睡和历史提醒；
- 新增专属素材部署状态，展示当前和上一私有 Release；
- 保留用户原图投稿、制作工单和异步串门脚本的动态工作区；
- 增加桌面、平板和手机响应式布局；
- 新增静态资源、CSP、DOM 完整性和 API 引用测试；
- CI 增加 `phase1.js` 语法检查。

## 数据与安全边界

- 浏览器账户令牌仅使用 `sessionStorage`，关闭当前浏览器会话后失效；
- 页面不使用外部脚本、外部图片、内联事件或内联脚本；
- 宠物状态、成长、消息已读、提醒和素材版本均由现有后端接口控制；
- Web 端不修改 PC 设备各自选择的当前宠物；
- 不引入 AI Agent、工具调用、文件执行或设备控制。
