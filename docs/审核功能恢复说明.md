# 宠物审核功能恢复说明

宠物原图投稿、人工审核、素材制作工单、模板审核发布和专属素材部署链路已恢复为默认运行功能。

恢复后应用启动时直接注册以下能力：

- 用户宠物原图投稿、列表、审核意见和鉴权图片下载；
- 管理员原图领取、通过和驳回；
- 素材制作工单、参考图、进度、失败重试和不可变制作产物；
- 模板版本审核、不可变发布、稳定通道与回滚；
- 专属素材独立审核、私有 Release、单宠 active/previous 指针、鉴权下载和回退；
- `/admin` 宠物内容管理台；
- 用户门户“专属形象”投稿与制作进度入口。

此前的 `MYPETS_ENABLE_PET_REVIEW` 功能开关已移除。数据库模型、历史投稿、工单、审核记录、Release 和对象文件继续沿用。
