# MyPets 发布检查清单

适用版本：`0.3.0a1`

## 一、版本与仓库状态

- [ ] `VERSION`、桌面 `pyproject.toml`、后端 `pyproject.toml`、桌面 `release.py` 和后端 `release.py` 版本一致；
- [ ] FastAPI `/health` 返回相同版本和发布通道；
- [ ] README、安装指南和实施计划没有合并冲突标记；
- [ ] README 不包含已删除或尚未实现能力的完成性描述；
- [ ] 工作分支已合并，发布提交可追溯；
- [ ] 发布标签与 `VERSION` 一致。

执行：

```powershell
.\.venv\Scripts\python.exe .\tools\release_check.py
```

## 二、自动化验证

- [ ] 后端全量测试通过；
- [ ] Web JavaScript 语法检查通过；
- [ ] Linux 桌面客户体验回归通过；
- [ ] Windows 全量测试通过；
- [ ] Qt 最终组合根启动验证通过；
- [ ] SQLite 升级、漂移、降级和重新升级通过；
- [ ] PostgreSQL 升级、漂移、降级和重新升级通过；
- [ ] 桌面和后端 Python 包编译通过。

## 三、Windows 客户端人工验收

- [ ] 首次运行引导可完整结束；
- [ ] 本地体验宠物可以完成五类照料；
- [ ] 云端登录和设备绑定成功；
- [ ] 当前宠物、伴随宠物和托盘状态一致；
- [ ] 关闭和重启后位置、设置和登录状态符合预期；
- [ ] 无网络、服务不可用和令牌失效均有明确提示；
- [ ] 退出应用后无遗留宠物窗口和异常后台进程；
- [ ] Windows 10 与 Windows 11 至少各验证一次；
- [ ] 单屏、多屏和不同缩放比例至少各验证一次。

## 四、Web 用户门户人工验收

- [ ] 注册、登录、退出和重新登录成功；
- [ ] 空账户自动进入领养第一只宠物流程；
- [ ] 用户界面不显示模板 ID 和版本号；
- [ ] 首页、宠物、好友、消息和更多导航可用；
- [ ] 手机宽度和桌面宽度均无关键操作遮挡；
- [ ] 加载、空状态、成功、失败和无权限反馈明确；
- [ ] 关闭浏览器会话后令牌行为符合说明；
- [ ] CSP、`no-store` 和安全响应头保持生效。

## 五、多账户业务验收

至少准备三个普通账户和四只宠物：

- [ ] 好友申请、接受、拒绝、取消、解除和屏蔽；
- [ ] 共同照料邀请、接受、拒绝和权限差异；
- [ ] 串门申请、接受、互动、提前返家和自动结束；
- [ ] 聚会邀请、选择宠物、接受、谢绝、开始、互动和结束；
- [ ] 已谢绝和已失效聚会成员看不到其他成员后续动态；
- [ ] 消息搜索、未读定位、读到这里和快捷回复；
- [ ] 提醒完成、贪睡、忽略和休眠恢复摘要；
- [ ] Web 与 Windows 待办数量、处理结果和当前宠物一致。

## 六、构建与压缩包

执行：

```powershell
.\scripts\package_release.ps1
```

检查：

- [ ] 生成 `dist\MyPets-Desktop-<版本>-windows-x64.zip`；
- [ ] 压缩包内包含完整 PyInstaller 目录，而非单独 EXE；
- [ ] 压缩包内包含 `VERSION`、`LICENSE` 和用户说明；
- [ ] 解压到新的无开发环境电脑后可以启动；
- [ ] 不包含 `user_assets` 原图、制作中间文件、数据库、密钥和日志；
- [ ] 未启用 `-IncludeUserAssets` 时不包含个人专属素材；
- [ ] 杀毒软件误报情况已记录。

## 七、服务端发布

- [ ] 配置 `MYPETS_ENVIRONMENT=production`；
- [ ] 使用至少 24 字符的独立随机 JWT 密钥；
- [ ] 配置正式 PostgreSQL；
- [ ] 执行 Alembic `upgrade head`；
- [ ] 保持生产环境启动时自动建表关闭；
- [ ] 使用 HTTPS 和反向代理；
- [ ] 配置对象存储持久化和备份；
- [ ] 管理员角色账号和默认密码已清理；
- [ ] 健康检查、日志、告警、备份和恢复方案已验证；
- [ ] 用户门户和管理端访问范围符合部署要求。

## 八、发布说明

- [ ] 明确标注 Alpha/Beta/Stable 通道；
- [ ] 列出新增功能、修复内容和已知限制；
- [ ] 明确 Windows 客户端是否包含服务端；
- [ ] 明确是否支持自动升级；
- [ ] 明确 AI、语音、小程序等未完成功能；
- [ ] 提供回退版本和回退步骤；
- [ ] 保存发布压缩包 SHA-256。

## 九、当前 Alpha 阻断项

下列事项未完成前，不应宣称正式稳定发布：

- 正式 Windows 安装和卸载程序；
- 自动升级或明确的手工升级迁移流程；
- 密码找回、设备自助管理和账户数据导出；
- 用户可操作的日志导出与诊断；
- Web 与 Windows 多账户真实交互验收记录；
- 远程生产环境的监控、备份和恢复演练。
